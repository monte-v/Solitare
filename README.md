## 🚀 Особенности

*   **Классический геймплей:** Полная реализация правил пасьянса "Косынка".
*   **Графический интерфейс:** Все элементы отрисованы с помощью SFML.
*   **Drag-and-Drop:** Перетаскивайте карты мышью.
*   **Чистый код:** Проект разбит на логические классы, соблюдаются принципы ООП.

## 📦 Технологии

*   **Язык:** C++17
*   **Библиотека:** SFML 3.0.0
*   **Сборка:** Visual Studio 2022
*   **Система контроля версий:** Git

## 🚀 Быстрый старт

Проще всего скачать готовую версию игры и сразу в неё поиграть.

### Скачать релиз (рекомендуемый способ)

1.  Перейдите в раздел **Releases** этого репозитория.
2.  Скачайте архив `Solitaire-v1.0.0.zip` для последней версии.
3.  Распакуйте архив в любую папку.
4.  Запустите файл `Solitaire.exe`.

> **Примечание:** В готовом релизе уже есть все необходимые DLL-файлы, поэтому игра запустится на любом компьютере с Windows 10/11.

## 🔧 Сборка из исходного кода (для разработчиков)

Если вы хотите посмотреть, как устроен код, или внести в него свои изменения, проект можно собрать самостоятельно. Для этого потребуется установить библиотеку **SFML**.

### Предварительные требования

*   Visual Studio 2022 с поддержкой C++.
*   Библиотека **SFML 3.0.0** для Visual C++ 17 (2022) 64-bit. [Скачать с официального сайта](https://www.sfml-dev.org/).

### Инструкция

1.  Клонируйте репозиторий.
2.  Откройте файл решения (`*.sln`) в Visual Studio.
3.  В свойствах проекта пропишите пути к папкам `include` и `lib` вашей установки SFML.
4.  Скопируйте DLL-файлы из папки `bin` вашей установки SFML в папку с собранным `exe`-файлом.

Более подробная инструкция по настройке SFML описана в [официальной документации](https://www.sfml-dev.org/documentation/3.1.0/).
